# 登录功能

## 背景 / 动机
未登录用户可以访问受保护页面，导致数据泄露风险。

## 功能点（三态：✅已确认 / 🟡默认方案 / ⚠️待确认）
- ✅ 未登录访问受保护路由重定向到登录页
- ✅ 登录成功后写入会话
- 🟡 会话有效期默认 30 分钟

## 范围
- 包含：登录页、会话写入、路由守卫
- 不包含：注册、找回密码、第三方 OAuth
